第一部分：乘法公式 中等

1. 展開 $(x+3)(x+5)$。

答：
解析： 利用 $(a+b)(c+d)=ac+ad+bc+bd$：$x \cdot x + x \cdot 5 + 3 \cdot x + 3 \cdot 5 = x^2 + 5x + 3x + 15 = x^2 + 8x + 15$。
答案： $x^2 + 8x + 15$

2. 展開 $(2x-1)(3x+4)$。

答：
解析： $2x \cdot 3x + 2x \cdot 4 + (-1) \cdot 3x + (-1) \cdot 4 = 6x^2 + 8x - 3x - 4 = 6x^2 + 5x - 4$。
答案： $6x^2 + 5x - 4$

3. 利用和的平方公式展開 $(x+7)^2$。

答：
解析： $(a+b)^2 = a^2 + 2ab + b^2$，令 $a=x, b=7$：$x^2 + 2 \cdot x \cdot 7 + 49 = x^2 + 14x + 49$。
答案： $x^2 + 14x + 49$

4. 利用差的平方公式展開 $(3x-2)^2$。

答：
解析： $(a-b)^2 = a^2 - 2ab + b^2$，令 $a=3x, b=2$：$9x^2 - 12x + 4$。
答案： $9x^2 - 12x + 4$

5. 利用平方差公式計算 $(x+6)(x-6)$。

答：
解析： $(a+b)(a-b) = a^2 - b^2$：$x^2 - 36$。
答案： $x^2 - 36$

6. 利用乘法公式計算 $51 \times 49$。

答：
解析： $51 \times 49 = (50+1)(50-1) = 50^2 - 1^2 = 2500 - 1 = 2499$。
答案： $2499$

7. 利用乘法公式計算 $103^2$。

答：
解析： $103^2 = (100+3)^2 = 10000 + 600 + 9 = 10609$。
答案： $10609$

8. 展開 $(2a+3b)(2a-3b)$。

答：
解析： 平方差公式：$(2a)^2 - (3b)^2 = 4a^2 - 9b^2$。
答案： $4a^2 - 9b^2$

第二部分：乘法公式進階 困難

9. 若 $x + \dfrac{1}{x} = 5$，求 $x^2 + \dfrac{1}{x^2}$ 之值。

答：
解析： 將 $x + \frac{1}{x} = 5$ 兩邊平方：$x^2 + 2 + \frac{1}{x^2} = 25$，故 $x^2 + \frac{1}{x^2} = 23$。
答案： $23$

10. 若 $a - b = 3$ 且 $ab = 10$，求 $a^2 + b^2$ 之值。

答：
解析： $(a-b)^2 = a^2 - 2ab + b^2 = 9$，故 $a^2 + b^2 = 9 + 2ab = 9 + 20 = 29$。
答案： $29$

11. 展開 $(x+2y-3)^2$。

答：
解析： 令 $A = x+2y, B = 3$，$(A-B)^2 = A^2 - 2AB + B^2$：$(x+2y)^2 - 2 \cdot 3(x+2y) + 9 = x^2 + 4xy + 4y^2 - 6x - 12y + 9$。
答案： $x^2 + 4xy + 4y^2 - 6x - 12y + 9$

12. 計算 $997 \times 1003$。

答：
解析： $(1000-3)(1000+3) = 1000^2 - 9 = 999991$。
答案： $999991$

13. 若 $a + b = 7, a - b = 3$，求 $a^2 - b^2$ 及 $ab$ 之值。

答：
解析： $a^2 - b^2 = (a+b)(a-b) = 7 \times 3 = 21$。又 $a = 5, b = 2$，$ab = 10$。
答案： $a^2 - b^2 = 21$，$ab = 10$

14. 展開並化簡 $(x+1)(x-1)(x^2+1)$。

答：
解析： $(x+1)(x-1) = x^2 - 1$，再乘 $(x^2+1)$：$(x^2-1)(x^2+1) = x^4 - 1$。
答案： $x^4 - 1$

第三部分：認識多項式 中等

15. 多項式 $3x^3 - 5x^2 + 2x - 7$ 是幾次多項式？最高次項係數為何？常數項為何？

答：
解析： 最高次為 $x^3$ 項，故為三次多項式。最高次項係數為 $3$，常數項為 $-7$。
答案： 三次多項式；最高次項係數 $3$；常數項 $-7$

16. 將 $4x - 2x^3 + 5 + x^2$ 以降冪排列寫出。

答：
解析： 按 $x$ 的次數由高到低排列。
答案： $-2x^3 + x^2 + 4x + 5$

17. 將 $7 - 3x^2 + x^4 + 2x$ 以升冪排列寫出。

答：
解析： 按 $x$ 的次數由低到高排列。
答案： $7 + 2x - 3x^2 + x^4$

18. 合併同類項：$5x^2 + 3x - 2x^2 + 7 - x + 4$。

答：
解析： $x^2$ 項：$5-2=3$；$x$ 項：$3-1=2$；常數：$7+4=11$。
答案： $3x^2 + 2x + 11$

第四部分：多項式的加減乘 中等

19. 計算 $(3x^2 + 2x - 5) + (x^2 - 4x + 3)$。

答：
解析： 同類項合併：$(3+1)x^2 + (2-4)x + (-5+3) = 4x^2 - 2x - 2$。
答案： $4x^2 - 2x - 2$

20. 計算 $(5x^2 - 3x + 1) - (2x^2 + x - 6)$。

答：
解析： $5x^2 - 3x + 1 - 2x^2 - x + 6 = 3x^2 - 4x + 7$。
答案： $3x^2 - 4x + 7$

21. 計算 $3x(2x^2 - x + 4)$。

答：
解析： $3x \cdot 2x^2 - 3x \cdot x + 3x \cdot 4 = 6x^3 - 3x^2 + 12x$。
答案： $6x^3 - 3x^2 + 12x$

22. 計算 $(x+2)(x^2 - 3x + 1)$。

答：
解析： $x(x^2-3x+1) + 2(x^2-3x+1) = x^3 - 3x^2 + x + 2x^2 - 6x + 2 = x^3 - x^2 - 5x + 2$。
答案： $x^3 - x^2 - 5x + 2$

第五部分：多項式除法與綜合應用 困難

23. 計算 $(6x^3 - 9x^2 + 12x) \div 3x$。

答：
解析： 每項除以 $3x$：$\frac{6x^3}{3x} - \frac{9x^2}{3x} + \frac{12x}{3x} = 2x^2 - 3x + 4$。
答案： $2x^2 - 3x + 4$

24. 計算 $(2x^2 + 5x - 3) \div (x + 3)$，求商式與餘式。

答：
解析： 長除法：$2x^2 \div x = 2x$，$2x(x+3)=2x^2+6x$，餘 $-x-3$。$-x \div x = -1$，$-1(x+3) = -x-3$，餘 $0$。
答案： 商式 $2x - 1$，餘式 $0$

25. 計算 $(x^3 - 8) \div (x - 2)$（注意缺項）。

答：
解析： 補缺項：$x^3 + 0x^2 + 0x - 8$。長除法得商 $x^2 + 2x + 4$，餘 $0$。
答案： 商式 $x^2 + 2x + 4$，餘式 $0$

26. 若多項式 $f(x)$ 除以 $(x-1)$ 的商式為 $(2x+3)$，餘式為 $5$，求 $f(x)$。

答：
解析： 被除式 = 除式 × 商式 + 餘式。$f(x) = (x-1)(2x+3) + 5 = 2x^2 + 3x - 2x - 3 + 5 = 2x^2 + x + 2$。
答案： $f(x) = 2x^2 + x + 2$

27. 化簡 $(x+3)^2 - (x-3)^2$。

答：
解析： 令 $A=x+3, B=x-3$，$A^2-B^2=(A+B)(A-B)=(2x)(6)=12x$。
答案： $12x$

28. 若 $(2x^2 + ax + b) \div (x - 2)$ 餘式為 $0$，且 $(2x^2 + ax + b) \div (x + 1)$ 餘式也為 $0$，求 $a, b$。

答：
解析： $f(2) = 8 + 2a + b = 0$，$f(-1) = 2 - a + b = 0$。由第二式 $b = a - 2$，代入第一式 $8 + 2a + a - 2 = 0 \implies 3a = -6 \implies a = -2, b = -4$。
答案： $a = -2, b = -4$

29. 一個長方形的面積為 $6x^2 + 7x - 20$ 平方公分，已知其中一邊長為 $(2x + 5)$ 公分，求另一邊長。

答：
解析： $(6x^2+7x-20) \div (2x+5)$。$6x^2 \div 2x = 3x$，$3x(2x+5)=6x^2+15x$，餘 $-8x-20$。$-8x \div 2x = -4$，$-4(2x+5) = -8x-20$，餘 $0$。
答案： 另一邊長為 $(3x - 4)$ 公分

30. 已知 $x - \dfrac{1}{x} = 3$，求 $x^2 + \dfrac{1}{x^2}$ 及 $x^4 + \dfrac{1}{x^4}$ 之值。

答：
解析： $(x - \frac{1}{x})^2 = x^2 - 2 + \frac{1}{x^2} = 9$，故 $x^2 + \frac{1}{x^2} = 11$。再平方：$(x^2 + \frac{1}{x^2})^2 = x^4 + 2 + \frac{1}{x^4} = 121$，故 $x^4 + \frac{1}{x^4} = 119$。
答案： $x^2 + \frac{1}{x^2} = 11$，$x^4 + \frac{1}{x^4} = 119$
