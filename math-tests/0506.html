第一部分：進階運算（含負數、倒數與分式不等式）

1. 解不等式：$-3(2x - 5) \ge 4x + 25$

答：
解析： $-6x + 15 \ge 4x + 25 \implies -10 \ge 10x \implies x \le -1$

2. 已知 $x$ 為負實數且 $\frac{1}{x} \ge - \frac{2}{3}$，求 $x$ 的範圍。

答：
解析： 因為 $x < 0$，兩邊同乘 $x$ 需變號：$1 \le -\frac{2}{3}x \implies -\frac{3}{2} \ge x$。故 $x \le -1.5$。

3. 比較大小：若 $a < b < 0$，請比較 $\frac{1}{a}$ 與 $\frac{1}{b}$ 的大小關係。

答：
解析： 負數的倒數，絕對值越小者（即較大的負數）其倒數反而較小。故 $\frac{1}{a} > \frac{1}{b}$。

4. 若 $-2 < \frac{1}{x} < 3$ 且 $x \neq 0$，求 $x$ 的所有可能範圍。

答：
解析： 分兩情況：(1) $x > 0$ 時，$\frac{1}{x} < 3 \implies x > \frac{1}{3}$； (2) $x < 0$ 時，$-2 < \frac{1}{x} \implies x < -\frac{1}{2}$。 故範圍為 $x > \frac{1}{3}$ 或 $x < -\frac{1}{2}$。

5. 已知 $x, y$ 為實數，若 $x < y < 0$，則 $\frac{1}{x-y}$ 與 $\frac{1}{y}$ 誰大？

答：
解析： $x-y$ 為負數且 $|x-y| < |x|$，但比較 $\frac{1}{x-y}$ 與 $\frac{1}{y}$。例：$-5 < -2 < 0$，則 $\frac{1}{-3}$ vs $\frac{1}{-2} \implies -0.33 > -0.5$。故 $\frac{1}{x-y} > \frac{1}{y}$。

6. 解不等式：$\frac{-2}{x+3} \ge \frac{1}{2}$。

答：
解析： 分母 $x+3$ 必須為負（否則左式為負，不可能 $\ge 0.5$）。 當 $x+3 < 0$ 時，兩邊同乘 $2(x+3)$ 變號：$-4 \le x+3 \implies -7 \le x$。 結合 $x < -3$，解為 $-7 \le x < -3$。

7. 若 $-3 \le a \le -1$ 且 $2 \le b \le 5$，求 $\frac{1}{a} + \frac{1}{b}$ 的最大值與最小值。

答：
解析： $\frac{1}{a} \in [-1, -\frac{1}{3}]$，$\frac{1}{b} \in [\frac{1}{5}, \frac{1}{2}]$。 最大值：$-\frac{1}{3} + \frac{1}{2} = \frac{1}{6}$； 最小值：$-1 + \frac{1}{5} = -\frac{4}{5}$。

8. 解分式不等式：$\frac{3}{x-2} < 0$。

答：
解析： 分子為正，故分母必須為負：$x - 2 < 0 \implies x < 2$。

9. 若 $ax + 5 < 3$ 的解為 $x > -1$，求常數 $a$ 之值。

答：
解析： $ax < -2$，解為 $x > -1$ 表示不等號變向，故 $a < 0$。且 $-\frac{2}{a} = -1 \implies a = 2$（不符）$\implies$ 修正邏輯：若 $ax < -2$ 且 $x > -1$，則 $a$ 必為 $-2$。$-2x < -2 \implies x > 1$。若要解為 $x > -1$，則 $a$ 應為 $2$ 但符號應為 $ax > -2$。 正確答案： $a = 2$ (原題意應為 $ax+5 > 3$ 的解為 $x > -1$)。

10. 比較大小：若 $x < y < 0$，則 $-3x^2$ 與 $-3y^2$ 誰大？

答：
解析： $x < y < 0 \implies x^2 > y^2 > 0 \implies -3x^2 < -3y^2$。故 $-3y^2$ 較大。

第二部分：絕對值不等式

11. 解不等式：$|2x - 7| \le 5$

答：
解析： $-5 \le 2x - 7 \le 5 \implies 2 \le 2x \le 12 \implies 1 \le x \le 6$。

12. 解不等式：$|3 - 4x| > 9$

答：
解析： $3 - 4x > 9 \implies -4x > 6 \implies x < -1.5$；或 $3 - 4x < -9 \implies -4x < -12 \implies x > 3$。

13. 若 $|x - a| \le 3$ 的解為 $-1 \le x \le 5$，求 $a$。

答：
解析： 範圍中心點為 $\frac{-1+5}{2} = 2$，半徑為 $3$。故 $a = 2$。

14. 解不等式：$|x - 2| + |x + 3| \le 7$

答：
解析： 分段討論：$x \le -3 \implies -2x - 1 \le 7 \implies x \ge -4$；$-3 < x < 2 \implies 5 \le 7$（全過）；$x \ge 2 \implies 2x + 1 \le 7 \implies x \le 3$。解為 $-4 \le x \le 3$。

15. 已知 $|ax + 2| \le b$ 的解為 $-2 \le x \le 6$，求 $a, b$ 之值。

答：
解析： 中心點 $x=2$，$2a+2=0 \implies a=-1$。此時 $|-x+2| \le b \implies |x-2| \le b$。距離 $6-2=4$，故 $b=4$。

第三部分：函數性質與邏輯推理

16. 已知一次函數 $f(x) = ax + b$ 滿足 $f(1) < f(2)$ 且 $f(3) > 0$，判斷 $f(-5)$ 是否可能大於 $0$？

答：
解析： $f(1) < f(2) \implies a > 0$（斜率為正）。$f(3) > 0$ 且函數隨 $x$ 減小而減小，故 $f(-5) < f(3)$。$f(-5)$ 可能大於 $0$（例如 $b$ 很大時），也可能小於 $0$。故答案為「可能」。

17. 直線 $y = mx + n$ 通過點 $( -2, 5 )$ 且斜率 $m < 0$。若該直線與 $y$ 軸交於正半軸，求 $n$ 的範圍。

答：
解析： $y-5 = m(x+2) \implies y = mx + (2m+5)$。故 $n = 2m+5$。已知 $m < 0 \implies n < 5$。又交於正半軸 $\implies n > 0$。故 $0 < n < 5$。

18. 若點 $A(k+1, 2k-5)$ 在第四象限，且到 $x$ 軸的距離小於到 $y$ 軸的距離，求 $k$ 範圍。

答：
解析： 第四象限：$k+1 > 0$ 且 $2k-5 < 0 \implies -1 < k < 2.5$。距離條件：$|2k-5| < |k+1|$。在該範圍內：$5-2k < k+1 \implies 4 < 3k \implies k > 4/3$。故 $4/3 < k < 2.5$。

19. 設函數 $y = |x - 2| + |x - 4|$，求使 $y \le 6$ 的 $x$ 範圍。

答：
解析： 分段討論或帶值：中心點 $[2,4]$ 間 $y=2$。向兩側增加。若 $x > 4$，$2x-6 \le 6 \implies x \le 6$。若 $x < 2$，$-2x+6 \le 6 \implies x \ge 0$。故 $0 \le x \le 6$。

20. 若 $x$ 的不等式 $ax + 1 > x + a$ 的解為 $x < 1$，求 $a$ 的範圍。

答：
解析： $(a-1)x > a-1$。因為解的方向改變（從 $>$ 變 $<$），故係數 $a-1 < 0 \implies a < 1$。

21. 已知 $x$ 為實數，且 $(k-2)x > 5$ 無解，求 $k$。

答：
解析： 若係數 $k-2 = 0$，則 $0 > 5$ 永遠不成立（無解）。故 $k = 2$。

22. 若 $-1 < x < 3$，求 $\frac{1}{x-4}$ 的最大值與最小值。

答：
解析： $x-4 \in (-5, -1)$。倒數後範圍為 $(-1, -1/5)$。最大值 $-1/5$，最小值 $-1$。

23. 設 $a, b$ 為常數，若 $ax + b > 0$ 的解為 $x < \frac{1}{3}$，求 $bx - a < 0$ 的解。

答：
解析： $ax > -b \implies x < -b/a$。故 $a < 0$ 且 $-b/a = 1/3 \implies a = -3b$。帶入 $bx - a < 0 \implies bx + 3b < 0 \implies b(x+3) < 0$。因 $a < 0$ 且 $b = -a/3$，故 $b > 0$。則 $x+3 < 0 \implies x < -3$。

24. 若關於 $x$ 的方程 $2x - a = 3(x + 1)$ 的解為負數，求 $a$ 的範圍。

答：
解析： $2x - a = 3x + 3 \implies x = -a - 3$。負數解 $\implies -a-3 < 0 \implies a > -3$。

25. 若 $|x-1| + |x-2| + |x-3| \ge k$ 對所有實數 $x$ 皆成立，求 $k$ 的最大值。

答：
解析： 左式最小值發生在 $x = 2$（中位數），值為 $|2-1| + 0 + |2-3| = 2$。故 $k \le 2$，最大值為 $2$。

第四部分：綜合應用問題

26. 傳送門啟動需要能量 $E$，滿足 $|2E - 500| \le 100$。若每單位燃料可產生 $15$ 單位能量，但會損耗 $5$ 單位穩定值（初始為 $100$，須大於 $0$）。求燃料單位數 $x$ 的範圍。

答：
解析： $200 \le E \le 300 \implies 200 \le 15x \le 300 \implies 13.33 \le x \le 20$。穩定值 $100 - 5x > 0 \implies x < 20$。故 $13.34 \le x < 20$。

27. 甲方案先打八折再減 $100$ 元；乙方案先減 $100$ 元再打八折。若消費者發現「甲」方案比「乙」方案便宜，但便宜不到 $50$ 元，求定價 $x$ 的範圍。

答：
解析： 甲：$0.8x - 100$；乙：$0.8(x-100) = 0.8x - 80$。乙 - 甲 = $20$。因為差距固定為 $20$ 元（恆便宜 $20$ 元），故只要定價 $x$ 讓方案合法（$x \ge 100$），甲永遠比乙便宜 $20$ 元且符合「不到 $50$ 元」。

28. 合金配比：甲含銅 $30\%$，乙含銅 $60\%$。欲混合成含銅量 $40\%$ 到 $50\%$ 之間（含）的合金共 $300$ 克，求甲合金克數 $x$ 的範圍。

答：
解析： $120 \le 0.3x + 0.6(300-x) \le 150 \implies 120 \le 180 - 0.3x \le 150 \implies -60 \le -0.3x \le -30 \implies 100 \le x \le 200$。

29. 馬拉松策略：前 $10$ 公里時速 $12$。剩下的 $30$ 公里想在 $2.5$ 小時內跑完，且時速 $v$ 滿足 $\frac{1}{v} \le \frac{1}{10}$，求 $v$ 的範圍。

答：
解析： 時間限制：$30/v \le 2.5 \implies v \ge 12$。倒數限制：$v \ge 10$。故 $v \ge 12$ km/h。

30. 三角形三邊長分別為 $5, 12, x$。滿足 $|x - 10| < 4$，求 $x$ 的範圍並判斷是否「必」為鈍角三角形？

答：
解析： 三角形性質：$7 < x < 17$。絕對值：$6 < x < 14$。交集 $7 < x < 14$。 鈍角條件：$x^2 > 5^2+12^2=169 \implies x > 13$；或 $12^2 > 5^2+x^2 \implies x^2 < 119 \implies x < 10.9$。 故當 $x \in (10.9, 13)$ 時為銳角或直角。答案：$7 < x < 14$，不一定。
